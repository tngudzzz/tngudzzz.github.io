MAU 25만 규모 자연드림 앱의 Flutter 개발·배포·운영을 3년 반간 전담했습니다. 커뮤니티·상품 탐색·상세·주문 내역의 Flutter 전환과 PHP API·Flutter Web 운영 도구 구축을 담당합니다. (MAU: 2026.10 기준)

경력

자연드림 · Flutter 앱 개발

2023.04 — 현재
  • Flutter 개발·배포·운영 1인 전담. 커뮤니티·푸시 보드는 앱/웹·PHP API 단독 구축, 장보기·주문 내역·예약·통합 홈은 Backend 협업.
  • 홈별 콘텐츠 처리 공통화와 장보기 단일 홈 전환 수행. 고객센터의 회원 정보·인증·접속일 조회와 푸시 대상 추출·발송을 운영자가 직접 처리하도록 운영 도구 구축.
  • DTO·Mapper 분리, 섹션 단위 파싱 오류 격리, 15개 화면 딥 링크 통합, 15개 의존성 수동 검증 화면·SDK 스모크 테스트 및 Sentry 오류 추적 적용.
  • Flutter 장바구니 개발에서 쿠폰·배송비·주문 전 검증, 선택 유지·수량 변경 실패 복구의 단위·위젯 테스트 추가. 해당 장바구니는 개발·검증 중이며 운영 미배포.

푸시 보드

· 반복적인 식별자 추출 요청 해소
2025.08 — 현재 · 운영 중
Flutter Web Riverpod PHP MySQL FingerPush
  • 타겟 발송 어드민을 제안하고 기획·Flutter Web·PHP API·배포까지 단독 구축.
  • 운영자의 직접 조회·발송으로 개발팀 식별자 추출 요청을 해소하고, 발송 절차를 3단계(문서 결재·개발팀 추출·FingerPush)에서 2단계(문서 결재·푸시 보드)로 전환.
  • 대량 CSV 청크 처리·500건 배치 전송·단계별 부분 실패 구분·30분 TTL 중복 요청 제한 구현.
  • 운영 규모: 월 약 700만 건(2026.10 확인).
